# Vocational-Training-at-IIIT-Naya-Raipur 🎓


This repository contains my work and learnings from the **Vocational Training Program at IIIT-Naya Raipur**.  
The training was structured week-wise, covering concepts from **Python basics to Reinforcement Learning** with hands-on practice and mini-projects.

---

## 📅 Weekly Learning Journey

### 🔹 Week 1: Python Programming
- Refreshed and deepened understanding of **Python concepts**.
- Worked on:
  - Data structures (lists, tuples, sets, dictionaries).
  - Functions, loops, conditionals.
  - File handling and basic libraries.

---

### 🔹 Weeks 2 & 3: Machine Learning
- Introduction to **Machine Learning** concepts.
- Implemented supervised & unsupervised learning models.
- Explored:
  - Linear Regression, Logistic Regression.
  - Decision Trees, Random Forest.
  - Clustering (K-Means, Hierarchical).
  - Model evaluation (accuracy, confusion matrix, etc.).

---

### 🔹 Week 4: Deep Learning
- Introduction to **Neural Networks**.
- Learned the basics of **TensorFlow/Keras**.
- Built and trained models on datasets.
- Covered concepts like:
  - Perceptron, Activation Functions.
  - Forward & Backward Propagation.
  - CNN basics.

---

### 🔹 Week 5: Reinforcement Learning
- Understood fundamentals of **Reinforcement Learning (RL)**.
- Key topics:
  - Agents, Environments, States, Actions, Rewards.
  - Markov Decision Process (MDP).
  - Implemented RL algorithms on **OpenAI Gym** environments (e.g., Taxi-v3, CliffWalking).
- Hands-on mini-projects for RL.

---

## 📂 Repository Structure
- `week1/` → Python basics exercises & notes.
- `Week2-3/` → Machine Learning implementations.
- `Week4/` → Deep Learning notebooks & models.
- `Week5/` → Reinforcement Learning experiments.
- `Assignments/` → Week-wise assignments given during training.
- `Mini_Projects/` → Additional small projects during training.
